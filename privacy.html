Privacy Policy

Violet Tomato, a Pomodoro timer Activity for Discord · Last updated: October 2, 2026

Violet Tomato ("the Activity") is a shared Pomodoro timer that runs inside Discord voice channels. It is made and operated by Elena Kovelskikh, an individual developer. This policy explains what information the Activity handles and what it does not.

The short version

The Activity does not ask for your Discord account details, does not use accounts, analytics, advertising or tracking cookies, and does not sell or share data for marketing. The only thing it stores is the state of the timer you share with the other people in your voice channel.

Information the Activity does not collect

The Activity does not request authorization to your Discord account. It does not receive or store your Discord username, user ID, avatar, email address, messages, voice or video.

Information the Activity stores

So that everyone in a voice channel sees the same timer, the timer's state is saved in a database. That state consists of:

  • the timer settings chosen for the session (number of rounds, long break length);
  • the current timer status (focus or break, when the current segment started, whether it is paused);
  • the session log: the start and end times of each completed focus round and break;
  • which parts of the shared screen are open (for example, the log or a settings popup).

This state is stored under a random identifier that Discord assigns to each launch of the Activity. It is not linked to any Discord user, and it does not record who pressed which button.

Service providers

The Activity relies on the following services, each of which processes technical data under its own privacy policy:

  • Discord runs the Activity inside its app and routes the Activity's network traffic through its own proxy, so the services below do not see your IP address when you use the Activity in Discord.
  • GitHub Pages hosts the Activity's files. Like any web host, it may keep standard request logs, which can include technical launch parameters that Discord adds to the address (such as identifiers of the Activity launch and the channel).
  • Google Firebase Realtime Database (hosted in the European Union, region europe-west1) stores the timer state described above.

Storage on your device

The Activity does not set cookies. The database library it uses may keep a small technical value in your browser's local storage to reconnect faster. It contains no personal information.

How long information is kept

Timer state is deleted automatically when the last participant closes the Activity. In rare cases (for example, if the last participants leave at exactly the same moment) a session can be left behind; such leftovers are removed from time to time by the operator and can be removed sooner on request. Because the state is not linked to any person, a request needs to say roughly when and in which server the session took place.

Children

The Activity is available only through Discord and is meant for people who are allowed to use Discord under Discord's own age requirements. It does not knowingly collect personal information from anyone.

Changes to this policy

If the Activity starts handling other information (for example, showing participants' names), this policy will be updated first and the date at the top will change.

Contact

Questions and requests can be sent by opening an issue at github.com/elenakovelskikh/pomodoro-timer-discord/issues.
